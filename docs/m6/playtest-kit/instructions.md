# Instructions (send)

Thank you for playing. Please read this page before you start, then play the game once, from the start to the end, recording the screen with sound.

## 1. Before you start

- **Don't look up the game** or watch anything about it. Please play without help. If you get stuck and want help, say so out loud, so it is in the recording.
- **You'll need about 30 minutes in all,** somewhere you can hear the game. **Sound on,** through headphones or speakers, whichever you normally use. Note which.
- A keyboard works; so does a game controller, if you prefer one.

## 2. Get the game

1. Unzip the file you were sent into a folder of its own.
2. Optional: check the file is the right one. Its SHA-256 should match the one you were given.
   - Windows, in PowerShell: `Get-FileHash dagon-windows.zip`
   - Linux, in a terminal: `sha256sum dagon-linux.zip`
3. Start it:
   - **Windows:** double-click `dagon.exe`. If Windows says it protected your PC, choose **More info**, then **Run anyway**: the game is not signed by a publisher, which is normal for a game-jam game.
   - **Linux:** double-click `dagon.x86_64`, or run `./dagon.x86_64` in a terminal in that folder. If it does not start, run `chmod +x dagon.x86_64` first.
4. You'll see the main menu. **Don't choose anything yet:** set up the recording first.

## 3. Record with sound

Any recorder that captures the screen **and the computer's sound** will do. The microphone is welcome too, if you're happy to think aloud, but it is not needed.

- **Windows, simplest:** the Xbox Game Bar. With the game window active, press **Windows + Alt + R** to start recording, and the same keys to stop. Recordings go to *Videos → Captures*. If nothing happens, press **Windows + G** once to open the Game Bar and check that recording is allowed.
- **Windows, also:** the Snipping Tool's video mode (**Windows + Shift + R**), with the sound button switched on, around the game window.
- **Windows or Linux:** OBS Studio (free, from obsproject.com). Add a *Display Capture* (Windows) or *Screen Capture (PipeWire)* (Linux) source, check that *Desktop Audio* moves on the meter, then **Start Recording**.
- **On Ubuntu,** the built-in screen recorder does not record sound; please use OBS.

**Test it first:** record ten seconds of the main menu while some sound is playing on your computer, play the recording back, and check that you can hear it. Then delete that test.

## 4. Play

1. **Start recording** with the main menu on screen.
2. Choose **New Game** and play the game through to the end, at your own pace, as you would on your own. Pausing is fine.
3. When the game is over, its last screens offer a way back to the **main menu**: take it when you're ready. Leave the main menu on screen for a few seconds, then **stop recording.**
4. If you have to stop part way, say so out loud before you stop, and tell us where you got to.

## 5. Afterwards

Please answer the five questions you were sent **straight away,** before talking to anyone about the game, and send them with the recording. A recording can be large; a cloud drive link is easiest.

Thank you!
