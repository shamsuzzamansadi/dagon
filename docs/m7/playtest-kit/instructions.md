# Instructions (send)

Thank you for playing. Please read this page before you start, then play the game once, from start to end, recording the screen with sound.

**Please send your recording and your answers by Sunday 29 November, 12:00 UTC.**

## 1. Before you start

- **Don't look up the game** or watch anything about it. Please play without help. If you get stuck and want help, say so out loud, so that it is in the recording.
- **Allow about 30 minutes in all,** somewhere you can hear the game. **Sound on,** through headphones or speakers, whichever you normally use. Note which.
- A keyboard works, and so does a game controller if you prefer one.

## 2. Get the game

1. Download the file for your computer from the link you were sent.
2. Optional: check that it is the right file. Its SHA-256 should match the one you were given.
   - Windows, in PowerShell: `Get-FileHash dagon-v0.2.0-alpha.2-windows-x86_64.zip`
   - Linux, in a terminal: `sha256sum dagon-v0.2.0-alpha.2-linux-x86_64.tar.gz`
   - Mac, in Terminal: `shasum -a 256 dagon-v0.2.0-alpha.2-macos-arm64.zip`
3. Unpack it and start it:
   - **Windows:** right-click the zip, choose **Extract All**, open the folders it makes until you see `dagon.exe`, and double-click it. If Windows says it protected your PC, choose **More info**, then **Run anyway**. The game is not signed by a publisher, which is normal for a game-jam game.
   - **Linux:** in a terminal, `tar xzf dagon-v0.2.0-alpha.2-linux-x86_64.tar.gz`, then `cd dagon-v0.2.0-alpha.2-linux-x86_64` and `./dagon.x86_64`.
   - **Mac (Apple Silicon, macOS 11 or later):** double-click the zip, then open **DAGON.app** in the folder it makes. The first time, macOS blocks it, because the app is not notarized by Apple:
     - **macOS 15 Sequoia or later:** choose **Done** when macOS says it could not verify the app. Open **System Settings**, then **Privacy & Security**, scroll down to **Security**, and choose **Open Anyway** beside the message about DAGON. Confirm with **Open Anyway** and your password.
     - **macOS 11 to 14:** Control-click the app, choose **Open**, then **Open** again.
4. You'll see the main menu. **Don't choose anything yet:** set up the recording first.

## 3. Record with sound

Any recorder that captures the screen **and the computer's own sound** will do. The microphone is welcome too, if you're happy to think aloud, but it is not needed.

- **Windows, simplest:** the Xbox Game Bar. With the game window active, press **Windows + Alt + R** to start recording, and the same keys to stop. Recordings go to *Videos → Captures*. If nothing happens, press **Windows + G** once to open the Game Bar and check that recording is allowed.
- **Windows, also:** the Snipping Tool's video mode (**Windows + Shift + R**), with its sound button switched on, around the game window.
- **Windows, Linux or Mac:** OBS Studio (free, from obsproject.com). Add a *Display Capture* source (Windows), *Screen Capture (PipeWire)* (Linux) or *macOS Screen Capture* (Mac, macOS 13 or later). Check that a sound meter in OBS's audio mixer moves while the game plays, then press **Start Recording**.
- **The built-in recorders on Ubuntu and on the Mac do not record the computer's sound.** Please use OBS there.

**Test it first:** record ten seconds of the main menu while some sound plays on your computer, play the recording back, and check that you can hear it. Then delete the test.

## 4. Play

1. **Start recording** with the main menu on screen.
2. Choose **New Game** and play through to the end at your own pace, as you would on your own. Pausing is fine.
3. When the game is over, its last screens offer a way back to the **main menu**: take it when you're ready. Leave the main menu on screen for a few seconds, then **stop recording.**
4. If you have to stop part way, say so out loud before you stop, and tell us where you got to.

## 5. Afterwards

Please answer the five questions you were sent **straight away,** before talking to anyone about the game, and send them with the recording **by Sunday 29 November, 12:00 UTC.** A recording can be large, so a cloud drive link is easiest.

Thank you!
